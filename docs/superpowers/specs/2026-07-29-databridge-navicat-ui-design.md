# DataBridge Navicat 风格界面改版 · 设计文档

日期：2026-07-29
状态：已与用户逐节确认

## 1. 背景与目标

现有 Web GUI 为三个顶部页（连接管理 / 数据浏览器 / 整表同步），以「连接/库/表」三级下拉框导航。用户希望界面改成 Navicat 式的操作形态。

经澄清，本次改版的核心诉求是**左侧对象树 + 右侧标签页布局**（非视觉主题化、非单元格编辑）：

- 左树：连接 → 库 → 表，懒加载展开；
- 双击表：在右侧打开该表的单表浏览标签，可同时打开多个表；
- 连接的增删改查/测试收进树的右键菜单 + 弹出对话框，取消独立「连接管理」页；
- 勾选行同步（本工具的核心特性，需要两张表同时在场）采用**专用「行同步」标签**：树右键「设为同步源/目标」装载左右双网格。

**本次为纯前端重构：后端 Python（engine/storage/service/web app.py）与全部 REST API 一行不改，现有 41 个 pytest 保持全绿。**

## 2. 需求决策记录

| 决策点 | 结论 |
|---|---|
| 核心诉求 | 左树 + 标签页布局（非视觉 reskin / 非编辑能力） |
| 行同步形态 | 专用「行同步」标签（单例），树右键装载源/目标 |
| 连接管理 | 收进树右键 + 弹框，删除独立连接管理页 |
| 实现路线 | 路线 A：重写 index.html 为 SPA 外壳，原生 JS 自建树/标签管理器，不引入框架，vendor 不变 |

## 3. 总体布局与标签生命周期

```
┌──────────────────────────────────────────────────────────────┐
│  DataBridge        [新建连接]                          （顶栏） │
├───────────────┬──────────────────────────────────────────────┤
│ 对象树 (左栏)  │  [ dev/app/users × ][ 行同步 × ][ 整表同步 × ] │ ← 标签栏
│               ├──────────────────────────────────────────────┤
│ ▾ dev         │                                              │
│   ▾ app       │            当前激活标签的内容                  │
│     • users   │        （单表网格 / 双网格 / 同步表单）        │
│     • orders  │                                              │
│   ▸ test      │                                              │
│ ▸ prod 🔒     │                                              │
└───────────────┴──────────────────────────────────────────────┘
```

- 外壳三区（`layout.js`）：顶栏、左树、右侧「标签栏 + 内容区」；左栏可拖拽调宽。
- 标签管理器（`tabs.js`）：
  - `openTab(key, title, renderFn)`：按 key 去重，已存在则激活。单表标签 key = `alias/db/table`；「行同步」「整表同步」为单例 key。
  - 切换：只显示激活标签，其余隐藏但保留 DOM 与状态（勾选、滚动位置不丢）。
  - 关闭：销毁该标签的 Tabulator 实例并移除 DOM。
  - 空状态：内容区显示「双击左侧表打开数据」。

## 4. 对象树与右键菜单

**结构与懒加载（`tree.js`）**

- 三层：连接（`GET /api/connections`，受保护带 🔒）→ 库（`GET /api/databases`）→ 表（`GET /api/tables`）。
- 首次展开才加载子节点；节点显示加载中状态；失败就地显示「加载失败，重试」，不弹全局错误、不拖垮整棵树。
- 各级右键均有「刷新」重新拉取子节点。

**交互**

- 双击表节点 → 打开单表浏览标签（去重）。
- 右键菜单（原生 JS 自绘，点击他处消失）：

| 节点 | 菜单项 |
|---|---|
| 树空白 / 顶栏按钮 | 新建连接… |
| 连接 | 编辑连接… / 测试连接 / 删除连接 / 刷新库列表 |
| 库 | 刷新表列表 |
| 表 | 打开表 / 设为同步源 / 设为同步目标 / 整表同步（以此为源）… |

**联动**

- 「设为同步源/目标」→ 打开或激活「行同步」标签，把该表装进对应侧；另一侧未装载时显示占位提示。
- 「整表同步（以此为源）」→ 打开「整表同步」标签，源侧预填。
- 连接增删改后：刷新树 + `invalidateConnections()` 失效缓存。

## 5. 标签内容与连接对话框

### 5.1 单表浏览标签（`tab-data.js`）

- Tabulator 远程模式：分页 / 列头筛选 / 排序（复用现 browser.js 面板的远程协议转换逻辑）；工具栏仅「刷新」。
- **无勾选列**：纯浏览；勾选只存在于行同步标签。
- **无主键的表允许浏览**（放开现有限制），仅在参与行同步时拦截并提示。

### 5.2 行同步标签（`tab-rowsync.js`，由 browser.js 迁移）

- 左源右目标双网格 + 勾选列 + 跨页按主键（`__pk`）记忆勾选顺序 + 「新增到目标 / 替换目标勾选行」按钮 + 确认框（受保护须勾选确认，请求体 `confirm:true`；护栏仍由服务层强制）。
- 装载入口：树右键「设为同步源/目标」；未装载侧显示「从左树右键选择表」。
- 迁移时修复评审遗留：
  1. 操作成功后清空源侧勾选（防重复追加）；
  2. 请求期间禁用操作按钮；
  3. 操作后自动刷新目标网格。

### 5.3 整表同步标签（`tab-tablesync.js`，由 sync.js 迁移）

- 源侧由树预填（只读显示 连接/库/表）；目标侧沿用级联下拉；WHERE、预览（dry-run）、执行、结果统计保留。
- 迁移时修复：切换连接清空下级下拉；执行期间禁用按钮。

### 5.4 连接对话框（`dlg-connection.js`，复用 `#modal` 弹层）

- 字段：别名 / 主机 / 端口 / 用户 / 密码 / 默认库 / 受保护；按钮：保存 / 测试连接 / 取消。
- 编辑态：**别名只读**（后端以别名为主键，改名等于复制，禁止歧义）；密码留空 = 不修改（测试连接已支持空密码回填旧密码）。
- 删除连接：右键 → `showConfirm` 确认。

| 文件 | 职责 | 状态 |
|---|---|---|
| `index.html` | 三区外壳骨架 + 样式（沿用卡片风格） | 重写 |
| `js/api.js` | api / toast / showConfirm / loadConnections | 保留不动 |
| `js/util.js` | `esc()` 等转义助手 | 新增 |
| `js/tabs.js` | 标签管理器 | 新增 |
| `js/tree.js` | 对象树 + 右键菜单 | 新增 |
| `js/dlg-connection.js` | 连接对话框 | 新增 |
| `js/tab-data.js` | 单表浏览标签 | 新增 |
| `js/tab-rowsync.js` | 行同步标签 | browser.js 迁移后删旧 |
| `js/tab-tablesync.js` | 整表同步标签 | sync.js 迁移后删旧 |
| `vendor/` | Tabulator 6.3.1 | 不变 |

数据流：所有组件只调既有 REST API。共享状态仅两处：`loadConnections()` 缓存（连接变更后失效）与 tabs 管理器持有的标签实例；`selOrder` 私有于行同步标签。

## 7. 错误处理与安全

- 统一走 `api()`：业务错误中文 toast（含 409 写入完整性冲突）；未知异常 500 只显示异常类名。
- 树节点加载失败就地重试，不影响其他节点。
- 受保护连接写入护栏由服务层强制（`_guard_write`），前端确认框仅为体验。
- **新代码统一防 XSS**：动态文本（树节点名、标签标题、确认框中的表名等）一律经 `textContent` 或 `esc()` 插入，不裸拼 innerHTML。

## 8. 验收

1. `node --check` 全部 JS 通过；`uv run pytest` 保持 41 通过（后端未动）。
2. 浏览器手工清单：
   - 树：懒加载、加载失败就地重试、各级刷新；
   - 标签：双击开表、key 去重、多标签切换状态保留、关闭销毁；
   - 行同步：右键装载源/目标 → 勾选（跨页）→ 新增/替换 → 成功后源侧勾选已清空、目标网格已刷新、请求期间按钮禁用；
   - 整表同步：树预填源 → 选目标 → 预览（目标不变）→ 执行（落库 + 统计）；
   - 连接对话框：新建 / 编辑（别名只读、空密码不改）/ 测试 / 删除确认；
   - 护栏：受保护目标未勾选确认无法提交；curl 不带 confirm 返回 403；
   - 无主键表：可浏览，进行同步时被拦截提示。
3. 可选：使用本机浏览器自动化（browser-use MCP）执行一轮冒烟。
